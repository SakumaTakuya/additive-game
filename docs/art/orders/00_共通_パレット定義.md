# アート発注指示書 #00 — 共通パレットの確定（最初にこれを決める）

> **すべての指示書がこのパレットを参照します。他のどのアセットよりも先に確定させてください。**

## 決めること

**24〜32色のスウォッチセット**。全アセットはこのセットからのみ配色します。

## 必要な色の系統

| 系統 | 用途 | 目安の色数 |
|---|---|---|
| **精霊質（最重要・全住人共通）** | 全住人の中身。目・炎・隙間として必ず露出する色 | **1〜2** |
| 遺跡の石・骨 | 背景ベース、石像、化石、壁画の獣、結晶の外殻 | 4〜5 |
| 土器・植物 | 壺、果実 | 2〜3 |
| 金属 | 鍵束、燭台の本体 | 2〜3 |
| 灯り・炎 | ランタン、燭台の炎（精霊質色と近いが別）、ホームアイコン | 2〜3 |
| 空・光 | 天気×時間帯の12レイヤー | 4〜6 |
| **影用（紫寄り）** | 全アセット共通の影1段 | 2〜3 |
| **寝ぼけ用（暗め・くすみ系）** | 敵＝精霊質が濁った個体へのパレットスワップ | **1系統（3〜4色。濁った精霊質色を含む）** |

## ★精霊質色について

このゲームの住人は全員、共通の「精霊質」（遺跡の魔力が形を得たもの）を中身として持ちます。
**#01 スライムの精霊はむき出しの精霊質そのもの**で、他の9体はそれが器に宿った姿です。

精霊質色は：
- 全住人で目・炎・隙間として露出する＝**群れの統一感の根拠**
- 淡く光って見える明度。ただしパレット内の色（発光色ではない）
- どの器の色（石・土器・金属・骨）の上に置いても沈まない
- 寝ぼけ系統には、この色の「濁った版」を1色含める

## ★寝ぼけ系統について

敵には**専用の絵を一切描きません**。既存の住人スプライトをこの系統に**パレットスワップするだけ**で表現します。
- どの住人に適用しても「同じ個体の、少し様子がおかしい状態」に見えること
- 「目つきが虚ろ」のような形状差分は作りません。**配色のみで成立させます**

## ★レア色について

各住人のレア色は**器の色違い**（中身の精霊質は同じ）。パレット内の別配色で作るため、
「同じ役割で色相の違う組」がいくつか必要です（例：石に対して青みの石／赤みの石）。

## パレット外が許される唯一の例外

**発光色**のみ。発光個体（出現率1%）は「精霊質が器から溢れて全身に満ちた状態」であり、
パレット外の発光色とハイライトを使えます。**明確に「格が違う」色**にしてください。

## 影のルール

- 影は**1段のみ**。色相は**紫方向**へ。各ベース色に対応する紫寄りの影色がパレット内に必要
- 光源は**左上・上方**で固定

## 納品形式

- スウォッチ画像（色番号付き）＋ 各色のHEX値一覧
- 確定後、各指示書の末尾「使用パレット記入欄」に番号を記入していきます

## 共通ルール（全アセット共通・厳守）

**画風**
- フラットな2Dベクター調。**アウトラインなし**。ベタ塗りのみで**グラデーション不使用**
- 質感描写ではなく「色面の構成」で見せる。情報量を抑え、**小サイズでシルエットが読めること**を最優先

**統一を担うのは次の3点だけ（それ以外は自由）**
1. **精霊質の色**：全住人の中身は共通の「精霊質」（遺跡の魔力が形を得たもの）。パレット指定の精霊質色が、目・炎・隙間のいずれかとして**必ず露出**する
2. **目の描法**：**全個体に目を必須**とする。描法は共通で「精霊質が光っている点」。形・数・位置は自由。同じ顔にはしない
3. **出自**：全員が「遺跡にあったものが目を覚ました」存在。本物の動物は入れない

頭身・シルエット・感情の方向は住人ごとに自由で、むしろ**バラバラであるべき**。

**配色**
- 共通パレット（24〜32色スウォッチ）からのみ配色。**1体あたり原則3〜5色**（精霊質色を含む）
- パレット外の色を使ってよいのは発光色アセットのみ
- 影は**1段のみ**・色相を紫方向へ／ハイライトは精霊質の露出部のみ許可（全身ハイライトは発光色のみ）
- 光源は**左上・上方**で固定／接地影は真下に**楕円1枚・ぼかしなし**

**姿勢**
- 発注する姿勢は**待機1姿勢のみ**。「静止」ではなく「**今ちょうど動きを止めた瞬間**」として描く（中立ポーズに倒すと置物になる）

**禁止事項（不変の設計原則）**
- 装備の重ね合わせを前提としたレイヤー分割をしない
- 複数方向（左右・斜め・背面）の素材を作らない。**正面固定**
- キャラの体格を共通化して素材を使い回す設計にしない（体格はバラバラでよい）

**納品**
- マスターはベクター（SVG等）で保持。PNGは書き出し成果物として納品
- ファイル名は本書指定のとおり（コードが同名で参照するため、**リネーム不可**）
- 各密度で書き出す場合は `drawable-mdpi/` 〜 `drawable-xxxhdpi/` に同名配置。1枚のみの場合は `drawable-nodpi/`
- 現在は全て仮画像が入っており、**同名ファイルの上書きだけで反映される**（コード変更不要）
