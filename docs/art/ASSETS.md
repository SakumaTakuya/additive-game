# 仮アセット一覧と本番差し替えガイド（v0.3）

> **アセット1点ずつの発注指示書は `docs/art/orders/` にあります**（[INDEX.md](orders/INDEX.md)）。
> 本ファイルは「どのファイルがどこに入るか」の対応表、orders/ は「何を描くか」の指示書です。

現在 `core/ui/src/main/res/drawable-nodpi/` に入っている画像は**すべて仮画像**（`tools/gen_placeholders.py` で生成。マゼンタの縁が目印）。
本番アセットは**同名ファイルを置き換えるだけ**で全サーフェス（Widget・通知・アプリ）に反映される。コード変更は不要。

## 差し替えルール

1. ファイル名を変えない（コード側の参照は `core/ui/.../Assets.kt` に一元化されている）
2. 各密度で書き出す場合は `drawable-nodpi/` の同名ファイルを削除し、`drawable-mdpi/`〜`drawable-xxxhdpi/` に同名で配置する
3. 追加モチーフ・追加段階が発生した場合のみ `Assets.kt` の配列に1行追加する

## コードで表現しているためアセット不要のもの

- **★表示・性格ラベル・開封カード枠・ログ枠・魔力ゲージ・ニックネーム欄**：Compose描画
- **寝ぼけ個体（敵）**：既存住人をくすみ系にパレットスワップ（色定義は #00）。PoCではバトルがログのみのため未使用
- **隊長トラッカーアイコン**：既存スプライトの縮小流用で開始。視認性不足時のみ `ic_tracker_XX.png` を追加
- **図鑑の未発見シルエット**：既存スプライトの黒抜きを実行時tintで生成
