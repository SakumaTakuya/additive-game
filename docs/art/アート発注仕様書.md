## 0. 前提と目的

- **用途**：顧客向けデモ。初見のリッチさが評価を左右するため、コア体験（Widget×常駐×レアドロップ）を見せる前に世界観と素材を先行して固める。
- **表示環境**：Androidホーム画面Widget（Jetpack Glance）＋通知（ステータスバー/シェード/ロック画面）。小サイズでの視認性が最優先。
- **収集の単位**：丸ごと差し替え可能な単位（住人1体／背景テーマ1枚）。パーツ合成・向き別素材は作らない。
- **住人の定義単位**：住人は**「器 × 中身 × 振る舞い」の3要素**で定義する。器の名前（「壺」）だけでは絵にしたとき物体になるため、単独では発注しない。
- 実装側の対応文書：設計書01〜04。1点ずつの発注指示書：`art-orders/`。

### 設計上の禁止事項（不変）

- 装備の重ね合わせを前提としたレイヤー分割をしない
- 複数方向（左右・斜め・背面）の素材を作らない。**正面固定**
- キャラの体格を共通化して素材を使い回す設計にしない（体格はバラバラでよい）
- **器の名前だけでモチーフを追加しない**（3要素が揃っていないものは住人ではない）

## 1. 世界観

ホーム画面の一角に、**発掘途中の古代遺跡**が現れている。遺跡には魔力が溜まりつつあり、その魔力は**精霊質**と呼ばれる、淡く光る半ば液体のような物質として現れる。

精霊質が満ちると、その辺の壺や石柱や鉱石までもが**目を覚まし、住人になる**。目を覚ました住人たちは、こちらが見ていない間もランタンを灯して遺跡の奥を探索し、何かを拾って帰ってくる。

固定の主人公はいない。**探索の主役は、プレイヤーが編成した3体のうち1枠目の「隊長」**である。プレイヤーが集めるのは装備ではなく「目を覚ました住人」と「遺跡の風景そのもの」。

### 中身の正体：精霊質

- 全住人の中身は共通の精霊質である。**むき出しの精霊質がスライムの精霊（#1）としずく（#2）**であり、他の8体は精霊質が器に宿った状態
- 精霊質は器の**目・炎・隙間**として必ず露出する。これが「生きている」ことの目印になる
- 寝ぼけて暴れる個体（敵）は、精霊質が**濁った**状態。発光色の個体は、精霊質が器から溢れて**全身に満ちた**状態

### 既存の設計との接続

| ゲーム内の言葉 | 実装・機能上の対応 |
|---|---|
| ランタンの魔力が尽きるまで探索 | 決定論的リソース。終了時刻確定・ローカル完結（設計書01） |
| **ランタン** | アプリとブランドのシンボル。アプリアイコン・通知アイコン・留守番役を兼ねる |
| 遺跡の上の空模様 | 天気API（固定地域の「今日の天気」。点火時にスナップショット固定／位置情報権限不要）。地域未設定・取得不可のときは晴れの空で描く |
| 曜日ごとの祭壇／月齢 | 日付から機械的に導出する疑似イベント（カレンダー権限不要）。遺跡には**材質ごとの祭壇**があり、曜日ごとに1つが灯る（木曜＝植物の祭壇など）。天井の「魔力の祭壇」とは別物。六曜はPoCで不使用 |
| 住人が目を覚ます | 毎周確定の覚醒ロール（★・性格・色の3軸） |
| 精霊質が濁った住人 | 敵。既存住人のパレットスワップ（敵専用アセット不要） |
| **隊長（編成1枠目）** | 通知シェードのトラッカーアイコンとしてゲージ上を歩いて帰る。**探索の主役** |
| 留守番組（非編成住人） | 探索中もWidgetに残り賑わいを作る |
| **最初の1体** | 初回起動時に#1を1体付与（★・性格・色は通常ロール）。序盤の画を埋める |
| 魔力の祭壇（天井） | 魔力を溜めて図鑑から選んだモチーフを確定で起こす「指名覚醒」 |
| **魔力に還す** | 重複個体を魔力素材へ戻す操作（旧称：変換） |
| 発掘袋 | 表示専用演出（探索中に膨らむ）。ゲージ・終了条件ではない |

## 2. スタイルガイド

### 2.1 画風の核（不変）

フラットな2Dベクター調。質感描写ではなく**色面の構成**で見せる。

- **アウトラインなし**（全キャラ・全背景要素で統一）
- ベタ塗り。グラデーション不使用
- 情報量を抑え、小サイズでもシルエットが読めることを最優先

### 2.2 統一感を担保するルール

統一を担う要素は**次の3点だけ**に絞る。それ以外（頭身・シルエット・感情の方向）は住人ごとに自由であり、むしろ**バラバラであるべき**。

**(1) 精霊質の色**：共通パレット内に**精霊質用の1〜2色**を確保し、全住人でこの色が目・炎・隙間のいずれかとして必ず露出する。

**(2) 目の描法**：**全個体に目を必須とする**（v0.2「目の有無自由」を撤回）。描法は共通で「精霊質が光っている点」として描く。形・数・位置は自由。同じ顔にはしない。

**(3) 出自**：全員が「遺跡にあったものが目を覚ました」存在。生き物モチーフもこの枷の中で選ぶ（本物の動物は入れず、化石・壁画・像として遺跡に存在していたもの）。

**共通パレット**：全アセットは共通の**24〜32色スウォッチセット**からのみ配色。1体あたり原則**3〜5色**（精霊質色を含む）。パレット外は発光色のみ例外（§6）。

**共通の描画ルール**：影は1段のみ・色相を紫方向へ／ハイライト原則なし（**精霊質の露出部のみ発光的な明色を許可**、全身ハイライトは発光色のみ）／光源は左上・上方固定／接地影は真下に楕円1枚・ぼかしなし。

### 2.3 形状

丸い／角ばった、縦長／横長は自由。**群れのシルエット多様性と感情の多様性を優先**。

### 2.4 顔・表情

- **目は必須**（§2.2）。精霊質の露出として描く
- 口・眉など他のパーツは自由
- 感情は**シルエットの変形と姿勢**で表現する。発注する姿勢は全住人**待機1姿勢のみ**（v0.2の主人公3姿勢は取り下げ）
- 待機姿勢は「静止」ではなく「**今ちょうど動きを止めた瞬間**」として発注する（§4の「振る舞い」列を参照）。中立ポーズに倒すと置物になる

### 2.5 サイズクラスと感情の方向

サイズは絶対dpで定義する（v0.2の「主人公の1/2」等の相対定義は廃止）。

| クラス | 基準サイズ | 見た目の役割 | ゲーム上の役割 | 感情の方向（傾向） |
|---|---|---|---|---|
| S | 48dp | 群れて賑わい | 支援・群れロール | かわいい／小生意気 寄り |
| M | 72dp | 標準的な住人 | アタッカーロール | 自由（かわいい〜不気味まで） |
| L | 120dp | 1体で存在感 | 壁ロール | かっこいい／威厳 寄り |

**感情の方向**は住人ごとに1つ割り振る（§4）。かわいい・かっこいい・ゆるい・不気味・威厳。厳選で「かっこいいのが★5で出た」「かわいいのがレア色で出た」と、当たりの嬉しさに種類を生むための軸。

Widget上（28〜56dp）では表情が読めないため、感情は**シルエットの語彙**で担保する：

| 感情 | シルエット語彙 |
|---|---|
| かわいい | 丸い・低重心・器が少し大きい（借り物感） |
| かっこいい | 鋭角・前傾・非対称 |
| ゆるい | 傾いている・中身がはみ出ている |
| 不気味 | 細長い・浮いている・炎や揺れ |
| 威厳 | 横に広い・左右対称・座り |

### 2.6 寝ぼけ個体の配色系統

共通パレット内に**暗め・くすみ系の1系統**を確保し、敵（寝ぼけ個体＝精霊質が濁った状態）はこの系統へのパレットスワップで表現する。精霊質色もこの系統内の濁った色に置換する。追加作画ゼロ。形状差分は作らない。

## 6. レアリティ表現（意味付けをv0.3で追加）

住人の個体差は**★（1〜5）・性格・色**の3軸。アセットに関わるのは色のみ。

| 色段階 | 発生率 | 表現 | **世界観上の意味** |
|---|---|---|---|
| 通常色 | 91% | 基本パレット | 精霊質が器に収まっている |
| レア色 | 8% | パレットスワップ（共通パレット内の別配色） | **器の色違い**。中身は同じ |
| 発光色 | 1% | 唯一の例外：パレット外の発光色＋全身ハイライト許可 | **精霊質が器から溢れて全身に満ちた状態** |

- レア個体は「別の姿」ではなく「同じモチーフの色違い」。形状・シルエットは一切変えない
- 発注単位：モチーフごとに通常＋レア色1種。発光は#1・#4・#5から開始（デモ最小セット §10）
