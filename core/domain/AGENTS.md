# :core:domain — 作業メモ

純 Kotlin。状態を変える操作（Ignite・Collect）とそのガードを置く。

- ガードは必ず永続状態から `derivePhase(record, clock.now())` で評価する（原則D）。画面の表示状態を引数に取らない
- ガードが不成立のときは**例外も通知も出さず何もしない**（Refresh だけ。01 §5）
- リポジトリはここではインターフェースだけ定義し、実装は `:core:data` に置く
- 時刻は `Clock` を受け取る。テストは時計を進める・戻すフェイクで、設計書01 §7 の異常系 #1〜#10 を再現する
